> [!WARNING]
>
> ### Реакция антивируса
>
> Антивирус может среагировать на WinDivert.  
> Этот компонент перехватывает и фильтрует сетевой трафик, поэтому он необходим для работы zapret.
> WinDivert способен использоваться разными программами, в том числе вредоносными, однако сам по себе вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)**
>
> Некоторые антивирусы классифицируют WinDivert как инструмент повышенного риска или хакерское средство. В таком случае файл удаляется и помещается в карантин. Название детекта обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса либо отключите проверку PUA (потенциально нежелательных приложений). Например, в Kaspersky есть настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Исключение лучше настроить внимательно; если назначение параметра вам непонятно, отключите обнаружение PUA.

## ⚙️ Использование

1. Сначала включите Secure DNS.
    * В Chrome активируйте пункт "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию".
    * В Firefox откройте настройку "DNS через HTTPS", выберите режим "Персональный", затем нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы. [Инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/); для Windows 11 этот вариант рекомендуется.
    * Владельцам роутеров Keenetic нужно включить в настройках параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.

2. Получите zip- или rar-архив на [странице последнего релиза](https://github.com/PennantBladeChaos/zapret-discord-youtube/releases/latest).

3. Откройте свойства загруженного архива и включите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот шаг можно не выполнять.

4. Распакуйте архив в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите нужный скрипт.
    * Для поиска рабочей стратегии откройте **`service.bat`** и выберите `Run Tests` -> `Standard tests` -> `All configs`.
    * Чтобы включить автозапуск, выберите в **`service.bat`** пункт `Install Service`, а затем подходящую стратегию.

## ℹ️ Файлы и их назначение

- [**`general.bat ...`**](./general.bat) запускает выбранную стратегию вручную.

  Ручной запуск удобен для проверки стратегий. Результат зависит от множества факторов, поэтому перебирайте варианты (**ALT**, **FAKE** и другие), пока не найдёте подходящий для своей сети.

- [**`service.bat`**](./service.bat) отвечает за автозапуск и дополнительные операции:
  - <ins>**`Install Service`** добавляет выбранную стратегию в автозапуск Windows (services.msc).</ins>
  - **`Remove Services`** удаляет стратегию и WinDivert из служб.
  - **`Check Status`** показывает состояние обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** меняет режим обхода для игр и прочих сервисов, использующих UDP и TCP на портах выше 1023.  
  После изменения параметра стратегию нужно перезапустить.  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** переключает фильтрацию ресурсов из `ipset-all.txt`.  
  Этот режим полезен при проверке ресурса, который без zapret доступен, но через zapret не работает.  
  Возможные статусы:
    - `none` — ни один IP не проходит проверку;
    - `loaded` — IP сравнивается со списком;
    - `any` — под фильтр попадает любой IP.
  - **`Auto-Update Check`** включает или отключает автоматический поиск обновлений.
  - **`Replace active fakes`** заменяет текущий используемый fake на другой из каталога `bin`.
  - **`Update IPSet List`** загружает актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** обновляет hosts <ins>для исправления веб-версии Telegram и подключения к голосовому чату Discord.</ins>
  - **`Check for Updates`** вручную проверяет наличие обновлений.
  - **`Run Diagnostics`** ищет распространённые причины неисправности zapret.  
  В конце диагностики доступна очистка кэша <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность клиента.
  - **`Run Tests`** запускает проверку стратегий:
    - `Standard tests` проверяет сайты из `utils/targets.txt`;
    - `DPI checkers` проверяет DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и неисправности

### После запуска `general*` ничего не видно

Отдельный bat-файл стратегии, запущенный не через service, должен открыть `winws.exe`. Процесс можно увидеть на панели задач. Если этого не произошло, обратитесь к [#522](https://github.com/PennantBladeChaos/zapret-discord-youtube/issues/522).

### Рабочей стратегии нет

- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается Telegram Web

В **`service.bat`** выберите **`Update hosts file`**. Если текущая версия hosts устарела, программа предложит обновить её вручную:

- Скопируйте весь текст из открывшегося блокнота.
- Откройте файл `hosts` в появившемся каталоге текстовым редактором, запущенным от имени администратора.
- Вставьте скопированный текст в конец файла `hosts` либо замените ранее добавленный аналогичный блок.
- Сохраните файл и проверьте подключение. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Результат не гарантируется. При отсутствии эффекта используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/PennantBladeChaos/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии не гарантируют постоянную работоспособность.**
> Обнаружение определённой стратегии может произойти спустя некоторое время, после чего она перестанет помогать.
> В этом репозитории собрано много вариантов обхода. Если готовые конфигурации не подходят, создайте новую на основе одной из них и измените её параметры.
> Описание параметров находится в [документации](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и убедитесь, что диагностика не сообщает об ошибках.
- Проверьте, присутствует ли адрес нужного ресурса в списках доменов или IP.
- Переберите другие стратегии, включая **`ALT`** и **`FAKE`**.
- Выполните полную переустановку по инструкции ниже.
- Дополнительная информация: [#765](https://github.com/PennantBladeChaos/zapret-discord-youtube/issues/765).

### Полная переустановка или обновление

- Сохраните добавленные вами ресурсы и данные.
- Перезапустите компьютер.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце выберите `Y`.
- Удалите старый каталог zapret.
- Загрузите свежую версию со [страницы релизов](https://github.com/PennantBladeChaos/zapret-discord-youtube/releases), например `zapret-discord-youtube-...`.
- Нажмите правой кнопкой мыши по архиву и откройте свойства. Если доступен флажок разблокировки, установите его, нажмите "Применить", затем "ОК".
- Распакуйте архив в новый каталог в корне диска. В пути не должно быть пробелов и специальных символов.
- Запускайте разные `general`-скрипты и проверяйте доступ к нужным ресурсам. Если интернет-ресурсы не открываются, закройте программу через значок замка на панели задач и попробуйте другую стратегию.
- Найдя рабочий вариант, включите автозапуск через `service.bat` -> `Install Service` и выберите эту стратегию.

### Игра или приложение не работает при включённом zapret

В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. В противном случае фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

Используйте инструкцию [по этой ссылке](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

### Windows 7 требует цифровую подпись драйвера WinDivert

В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Узнайте имя службы в командной строке Windows. Нажмите Win+R, введите `cmd`, затем выполните:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8F-использование).
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться.
- Перепробуйте остальные стратегии, особенно если прежняя конфигурация раньше работала.
- См. также [#251](https://github.com/PennantBladeChaos/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8F-использование) настроен.
- Сначала определите стратегию, на которой открывается YouTube, и запустите её.
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord.
- Проверьте, заработало ли приложение Discord после очистки.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, временно пользуйтесь ей.
- Если браузерная версия также недоступна, снова проверьте все стратегии. YouTube и Discord могут требовать разные варианты.
- Дополнительные сведения: [#252](https://github.com/PennantBladeChaos/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/PennantBladeChaos/tg-ws-proxy).
- Также можно использовать бесплатные MTProto-прокси, доступные в интернете.

### Игры не подключаются

Игр много, поэтому проверить и исправить каждую из них отдельно невозможно.

Начните с универсальной последовательности:

- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

У `ipset any` есть побочный эффект: многие сайты могут перестать открываться. Не оставляйте этот режим включённым постоянно. Определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/PennantBladeChaos/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Ответа на проблему нет

Опишите её [в разделе issues](https://github.com/PennantBladeChaos/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Список обхода расширяется через следующие файлы:

- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например когда IP-сеть присутствует в `ipset-all.txt`, но отдельный домен из неё фильтровать не требуется;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, подлежащие исключению.

Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
